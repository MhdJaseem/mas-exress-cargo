# Maintenance guide

| Task                                     | How                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Edit text on a service page              | `src/data/services.ts` — find the service by `slug`, edit the block (`paras`, `cards`, `steps`, `stats`, `table`, `faq`)                                                                                                                                                                                                                                 |
| Edit a solution page                     | `src/data/solutions.ts` (paragraphs, photo, related services, pickup mode)                                                                                                                                                                                                                                                                               |
| Edit About / Team / Branches content     | `src/data/company.ts` (testimonials, clients, CEO message, team groups, branches); page layout in `src/pages/*Page.tsx`                                                                                                                                                                                                                                  |
| Edit home page text                      | the section component in `src/components/home/`                                                                                                                                                                                                                                                                                                          |
| Change phone numbers / emails / address  | `src/lib/site.ts` (header, footer, contact card, WhatsApp, service sidebars read from it). Branch numbers are in `src/data/company.ts`. Then search the repo for the old number (e.g. hero Call card)                                                                                                                                                    |
| Change header / footer / WhatsApp markup | `src/components/layout/Header.tsx`, `Footer.tsx`, `WhatsAppWidget.tsx` — applies to every page                                                                                                                                                                                                                                                           |
| Change brand colours                     | `:root` tokens at the top of `src/styles/main.css`                                                                                                                                                                                                                                                                                                       |
| Replace a photo                          | Overwrite the file in its `public/img/<group>/` folder (same name) or add a new one and update the path in the data/component. Keep ≤ 250 KB, ≥ 1600px wide for heroes                                                                                                                                                                                   |
| Replace the About video                  | Replace `public/video/about-crane.mp4` and `public/img/sections/about-poster.jpg` (H.264, no audio, ≤ 1 MB)                                                                                                                                                                                                                                              |
| Add a testimonial                        | Add an entry to `testimonials` in `src/data/company.ts` — it appears on the home marquee and the About page                                                                                                                                                                                                                                              |
| Add a service page                       | Add an entry to `services` in `src/data/services.ts` (slug, name, icon, mode, hero image in `public/img/pages/`, title, lead, blocks). The route, header, footer, sidebar and chips update automatically. Add a home card in `ServicesSection.tsx` if wanted, and the `.html` redirect in `public/_redirects` / `vercel.json` only if an old URL existed |
| Add any other page                       | Create `src/pages/XPage.tsx` (use `PageHero` + `.pbody.solo`, `useDocumentMeta`, `useReveal('inner')`), add a route in `src/router.tsx`, link it from `Header.tsx` / `Footer.tsx`                                                                                                                                                                        |
| Add an icon                              | Add a `<symbol>` to `src/components/layout/IconSprite.tsx` and its name to `IconName` in `src/components/ui/Icon.tsx`                                                                                                                                                                                                                                    |
| Update stats                             | home: `AboutSection.tsx` (`CountUp value`); air freight: `stats` block in `services.ts`                                                                                                                                                                                                                                                                  |

## Working with Claude Code

Open the repo in VS Code with Claude Code. `CLAUDE.md` already tells it the rules. Good prompts: "Add a Solutions page using the company-page layout and this text…", "Convert hero images to WebP with srcset", "Implement trackShipment in src/lib/api.ts against this API spec", "Add Playwright tests for every route at 390px". Always ask it to run `npm run build` and re-check mobile.
